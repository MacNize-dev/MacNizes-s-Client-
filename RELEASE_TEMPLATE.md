### 🚀 Instalação Rápida

**PojavLauncher:**
```
Settings → Custom Mods → Import .jar → Selecione o arquivo
```

**ZalithLauncher:**
```
Copie para: /sdcard/ZalithLauncher/mods/
Reinicie o launcher
```
