## 🚀 Instalaçao Rápida

### Via PojavLauncher (Android)
```
1. Baixe o arquivo .jar
2. Abra PojavLauncher
3. Settings → Custom Mods → Select .jar file
4. Selecione o arquivo baixado
5. Play → Selecione "MacNize's Client"
```

### Via ZalithLauncher (Android)
```
1. Baixe o arquivo .jar
2. Coloque em: /sdcard/ZalithLauncher/mods/
3. Reinicie ZalithLauncher
4. Selecione "MacNize's Client" como versão
5. Clique em Play
```

### Via TLauncher (Windows/Mac)
```
1. Baixe o arquivo .jar
2. Windows: %appdata%\.tlauncher\mods\
   Mac: ~/Library/TLauncher/mods/
3. Reinicie o launcher
4. Selecione o cliente
5. Play
```
