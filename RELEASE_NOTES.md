## 🚀 Instalação Rápida

### PojavLauncher (Recomendado)
```
1. Baixe: MacNizes-Client-1.0.0.jar
2. PojavLauncher → Settings → Custom Mods
3. Import .jar
4. Selecione "MacNize's Client" como versão
5. Clique em "Play"
```

### ZalithLauncher
```
1. Copie o .jar para: /sdcard/ZalithLauncher/mods/
2. Reinicie o launcher
3. Selecione "MacNize's Client"
4. Clique em "Play"
```

### TLauncher (Windows/Mac)
```
1. Coloque em: %appdata%/.tlauncher/mods/ (Windows)
2. Reinicie o launcher
3. Selecione o cliente
4. Clique em "Play"
```

## 🛠️ Troubleshooting

### O Cliente não inicia
**Solução:**
- Aumente RAM alocada: `-Xmx2G -Xms1G`
- Verifique Java 11+
- Limpe cache e reinstale

### FPS muito baixo
**Solução:**
1. Ative FPS Booster Nível 5
2. Reduza Render Distance para 12
3. Desative Dynamic Lights
4. Desative Shaders
5. Ative Battery Saver Mode

### Shaders não funcionam
**Solução:**
- Verifique Java 11+
- Aumente RAM para 2GB+
- Desative outros módulos gráficos
- Use shader "Low" primeiro

### Crash em servidor online
**Solução:**
- Desative Discord RPC
- Reduza render distance
- Verifique regras do servidor
