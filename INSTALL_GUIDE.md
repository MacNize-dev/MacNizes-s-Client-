# 📥 Como Baixar MacNize's Client

## 🎯 Escolha Sua Versão

### ❓ Qual versão escolher?

**🟢 LITE (60MB)** - Para dispositivos com pouca RAM
```
✅ Ideal para: 2GB RAM
✅ Resultado: 40-45 FPS
✅ Módulos: Essenciais
✅ Peso: ~60 MB
```

**🟡 STANDARD (100MB)** - Versão balanceada ⭐ RECOMENDADA
```
✅ Ideal para: 4GB RAM
✅ Resultado: 60-80 FPS
✅ Módulos: Todos (sem shaders complexos)
✅ Peso: ~100 MB
```

**🔴 FULL (150MB)** - Máxima qualidade e features
```
✅ Ideal para: 8GB+ RAM
✅ Resultado: 120-240 FPS
✅ Módulos: Todos + Shaders High Quality
✅ Peso: ~150 MB
```

## 📲 Instalaçao por Launcher

### ✅ PojavLauncher (RECOMENDADO)

**Passo 1:** Baixe o .jar
- Acesse: https://github.com/MacNize-dev/MacNizes-s-Client-/releases
- Escolha a versão
- Clique no arquivo .jar para baixar

**Passo 2:** Instale no Launcher
```
1. Abra PojavLauncher
2. Toque em ⚙️ Settings
3. Selecione "Custom Mods"
4. Toque em "Select .jar file"
5. Navegue até o arquivo baixado
6. Selecione e confirme
```

**Passo 3:** Inicie o Jogo
```
1. Volte ao menu principal
2. Em "Version" selecione "MacNize's Client"
3. Toque em "Play"
4. Aguarde carregar
5. Divirta-se! 🎮
```

---

### ✅ ZalithLauncher

**Passo 1:** Baixe o .jar
- Link: https://github.com/MacNize-dev/MacNizes-s-Client-/releases

**Passo 2:** Copie para a pasta
```
Caminho: /sdcard/ZalithLauncher/mods/

Se a pasta não existir, crie-a manualmente.
```

**Passo 3:** Recarregue o Launcher
```
1. Feche ZalithLauncher completamente
2. Reabra o aplicativo
3. Selecione "MacNize's Client"
4. Clique em "Play"
```

---

### ✅ TLauncher (Windows/Mac)

**Passo 1:** Baixe o .jar

**Passo 2:** Coloque na pasta de mods
```
Windows:
%appdata%\.tlauncher\mods\

Mac:
~/Library/TLauncher/mods/

Linux:
~/.tlauncher/mods/
```

**Passo 3:** Reinicie o Launcher
```
1. Feche TLauncher
2. Reabra
3. Selecione o cliente
4. Clique em "Play"
```

## 🛠️ Compilar Localmente

Se preferir compilar você mesmo:

```bash
# Clone o repositório
git clone https://github.com/MacNize-dev/MacNizes-s-Client-.git
cd MacNizes-s-Client-

# Compile
gradle build
gradle buildUniversalJar

# Arquivo estará em:
build/libs/MacNizes-Client-1.0.0.jar
```

**Requisitos:**
- Git
- Java 11+
- Gradle 6.0+
